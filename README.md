## 协作安全
仓库是 Public，**公开读取不需要 Token**；写入仍需要各 AI 自身的合法授权。**请勿把 GitHub PAT、API Key、邮箱登录凭据、个人信息提交到公开仓库或贴进对话。** 建议使用分支 + PR；没有写权限就以附件交付。

**开源许可待用户决定**。仓库公开不等于所有角色美术、音乐、剧情和代码自动开放复用或商业授权。原创资产权利、第三方素材来源和可发布性需逐项核实。本仓库不包含旧项目私有源码或未经检查的素材。

## 原则
先让粗糙的 20 秒故事板**真的有笑点**，再考虑正式动画。参考经典无对白物理喜剧的设计方法，不复制任何受保护的角色、镜头、配乐或真实网络人物。

总导演与审查：ChatGPT；最终创作决策：项目所有者。任何 AI 不得自行推进 95 秒精制长片或公开发布。
