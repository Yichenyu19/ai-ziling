# 《AI嘉豪》20 秒验证片 ·《大师的风范》
**版本**：导演实验稿 0.1（允许故事 AI 提出更聪明的改法；不得凭空增加随机事故）。无对白，预定 20 秒、30fps、16:9；低成本二维 Animatic，不必正式骨骼绑定。

## 角色
- **嘉豪**：原创虚构成年角色，黑色系兜帽，白色眼睛或简洁面部。幻想自己是 AI 世界的大师，非常在乎直播镜头的尊严；略懂技术、有一点真本事，但爱装。面对危险第一反应不是大叫，而是看摄像头有没有拍到。
- **AI 助手**：简洁可爱、执拗认真的原创二维机器人。真心把嘉豪拍好；从“直播画面稳定/好看”判断成功，不是恶意破坏者。看见完美画面会得意，会主动调整设备，最终珍惜截图。

## 空间 / 物理规则（必须先画平面图）
客观视角：可滚动的摄影推车在左、嘉豪居中、风机在右、风朝左吹；插座在右侧固定墙面；供电线经过推车可行进的地面区域，轮子可能卷住线圈。
- 风机推动人向左；嘉豪脚勾住推车后，人和推车一起向左移动，因相对机位变化小，直播画面反而显得稳定。
- 观众要事先看到推车轮子和电线的关系，且线有松弛量、能够绷紧；拉脱插头需要有效的线方向/受力和限位，不能凭空“自然拔掉”。
- **重要：断风之后嘉豪如何摔倒必须符合前一帧重心和受力。** 他在抵抗左吹风时会向右压重心；断风后更可能向右踉跄。可在故事板验证后调整动作，不能只为了笑点把角色随意往地上砸。
- 风机/镜头/桌腿/线缆的摆位在不同镜头里一致；小助手不得瞬移。

## 20 秒故事节拍（可重排，不要生硬地同时显示一切）
| 时段 | 表演与观众信息 |
|---|---|
| 0–2.2 | 嘉豪史诗级神秘登场，气氛隆重。 |
| 2.2–4.3 | 切客观全景：普通房间 + 手机拍摄 + AI 调风机。主观史诗 / 客观现实的第一次落差。 |
| 4.3–6.5 | 风先让嘉豪很帅，随后兜帽遮眼；他看镜头，偷偷把兜帽按回去，继续装。 |
| 6.5–8.4 | 风继续加大，他向左滑，脚偷偷勾住摄影推车。短暂停顿，误以为稳了。 |
| 8.4–11.1 | 推车开始跟他一起向左滚，手机直播画面竟然保持构图。**第一次动作因果笑点**。 |
| 11.1–13.4 | AI 看见好画面主动加大风；嘉豪接近撑不住，仍假装从容。 |
| 13.4–15.6 | 低角度插入轮子与线圈，观众先发现潜在危险。另一方面直播画面巧合得像英雄起飞，AI 截图。 |
| 15.6–18.3 | 线绷紧拔掉风机电源；风停，嘉豪因先前发力与重心失衡摔倒/踉跄，音乐断。具体方向由物理和姿势验证。 |
| 18.3–20.0 | AI 展示刚刚截到的英雄照片，现实里的嘉豪狼狈极了；嘉豪看着照片忍不住重新摆出大师架势。**角色反转与回收**。 |

## 必须做的六个清晰姿势
1. 传奇大师的仪式性登场。
2. 不破坏上半身冷酷气质、偷偷按兜帽。
3. 上半身耍帅、下半身难看地用脚勾推车。
4. 快撑不住却在镜头前突然镇定。
5. 快水平/倾斜的英雄姿态（在直播角度里更帅，现实里很狼狈）。
6. 摔倒后看见照片，立刻恢复大师形象。

## 导演原则
- 每个包袱遵循：角色要什么 → 采取行动 → 观众看到危险 → 后果反噬 → 角色独有的反应。
- 不要靠长台词、屏幕小字或弹幕解释笑点。静音观看也应成立。
- AI 助手的积极行动（调整风、截图、展示照片）必须在镜头里可见。
- 不要动画每秒都炸：为预期、犹豫、羞耻和恢复风范留真正的停顿。
- 不允许随便使用 Alan Walker 音乐、真实嘉豪梗原视频和猫和老鼠片段；只借鉴高级喜剧设计方法。
