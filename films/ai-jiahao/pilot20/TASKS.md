# 多 AI 生产编排：先分工，再整合
总导演 / 制片统筹：ChatGPT 与用户。Hark 执行 AI 只负责明确的工作包，不自行扩展长片。

## A · 故事导演 / 物理喜剧
**输入**：`DIRECTOR_BRIEF.md`。
**输出文件域**：`films/ai-jiahao/pilot20/story/`（与 B、C 绝不冲突）。
**任务**：
- 建立 12–20 格明确时间、镜号、景别、行动/反作用/心理意图的分镜；可用 SVG 粗画或简单图。
- 用平面图证明每个装置如何相互作用。特别审判断风后的摔倒方向、供电线位置是否站得住。
- 给 3 个可替换的强笑点（尤其最后 2 秒），从中选有最完整因果、最嘉豪的一种；拒绝随机爆炸。
- 输出 `story/BEATS.md`、`story/PHYSICS.md`、`story/BOARD.*` 和自评。
**完成条件**：即使只有火柴人草图，第三方能无字幕理解发生了什么。不得擅自制作正式 20 秒成片。

## B · 角色美术 / 表演 / 舞台设计
**输入**：`DIRECTOR_BRIEF.md`；与 A 可并行。
**输出文件域**：`films/ai-jiahao/pilot20/art/`。
**任务**：
- 设计原创成年嘉豪及原创 AI 助手，一张一致比例的角色设计页：正面、侧面、表演六姿势、眼神与体态区分。
- 单独绘制固定房间平面图、摄影推车、风机、墙上插座、线圈与 AI 位置，保证舞台自洽。
- 低成本可复用资产（SVG、PNG、或可编辑源），不得借用真实梗视频人物肖像。
- 输出 `art/CAST_SHEET.*`、`art/SET_LAYOUT.*`、`art/ASSET_LIST.md`，标示原创/来源。
**完成条件**：缩至 390px 仍认得出嘉豪在装酷和 AI 助手在认真做事；不中断 A 的分镜工作。

## C · 技术预演 / 动态故事板工程
**输入**：`DIRECTOR_BRIEF.md`；前期仅构建轻量渲染框架，待 A/B 导演审核通过后整合。
**输出文件域**：`films/ai-jiahao/pilot20/animatic/`。
**任务**：
- 评估可复用 `ai-yangwei` 的 Canvas/FFmpeg/Python 相关设施；选择最轻量方案，不引入大引擎。
- 先交可复现的 20s/30fps/16:9 空白舞台时间轴 + 临时原声机制，含必要的镜头切换接口；这一阶段不能擅自替 A/B 设计剧本和美术。
- 接到总导演确认的 A、B 产物之后，才将分镜/图形做成真正 20 秒 MP4 Animatic，低成本临时声音、关键姿势准确、可反复修改。
- 输出 `animatic/BUILD.md`、可运行源码、MP4、关键帧图、验收日志；注明是否实际看过、听过。
**完成条件**：`build` 命令可复现 MP4；画面运动的因果可读；不是只有一份“计划书”。

## D · 独立审片（排在整合后，不要现在虚假提前验收）
**输入**：C 交付的真实 MP4 和 A/B 交付的标准。
**输出**：`films/ai-jiahao/pilot20/review/REVIEW.md`。
**任务**：静音、原速、有声、390px、运动因果逐项检查，给明确“保留 / 精修 / 否决”；没能力正常播放要如实说明。不得把制作方自检当外部观众证据。

## Git 协作协议
- 所有人对照项目分支 `main`（新公开仓库）；**不得直接改 main**。
- AI 只写各自文件域，在个人功能分支提交 PR，或以附件交付、由制片统筹审查后合入。不得相互覆盖。
- 本仓库公开可读；写入需各 AI 自己具有合法授权，严禁用户在聊天里发送 GitHub Token。
- 不声称任务已完成，除非交付具体文件/可验证链接；给出 commit、构建命令、限制和未验证事项。
- 权限不够就先返回可移植文档/素材附件，不能假装访问成功。

## 公开仓库补充协作规则
- **A/B/C 不直接向 main 提交**：各自只修改分配的目录，使用 PR 或附件由统筹整合。
- 原 `ai-yangwei` 私有仓库中的代码资产只有得到授权、完成许可审查后才能迁入这里。不要复制私人资料或访问凭据。
- 主导演确认 A 的物理机关与 B 的造型方案前，C 只允许构建占位符工程，不能用未经审核的方案做精细片。
- 公开目录只存准备对外展示的材料，参考图来源不明的一律不要上传。
